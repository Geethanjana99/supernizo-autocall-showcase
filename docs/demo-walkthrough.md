# Demo walkthrough

Use a test site and test accounts when recording a demonstration. This walkthrough describes a product demonstration; it is not a public hosted demo or an automated test result.

## 1. Show the agent workspace

Open the live visitor dashboard and select the demonstration site. Point out the online visitor list, current-page context, and available conversation actions.

## 2. Bring a visitor online

Open the test website in a separate browser context. Browse a few pages and show how the visitor's session context appears in the agent dashboard.

## 3. Start a conversation

Send a message through the website chat widget. Open the conversation from the agent dashboard and reply. Show the two sides of the exchange.

## 4. Demonstrate an incoming call

Send an audio call invitation from the dashboard. Show the visitor's incoming-call popup and ringtone, then accept and grant microphone access. Show the connected call controls and end the call.

Repeat with a video invitation if the demonstration devices have cameras available. Show the decline path separately so viewers can see the visitor's choice.

## 5. Demonstrate a visitor request

Use the website's call action to request an audio call from the team. Show the incoming-call alert and dashboard ringtone, then accept from the agent workspace.

## 6. Show follow-up and history

Use fictional contact details in the optional follow-up form. Show the staff conversation status and the retained message or call history after the interaction.

## Suggested recording sequence

Live visitor dashboard → website visitor → chat exchange → incoming call → visitor acceptance → connected call → interaction history.

Capture the visitor and agent screens side by side where possible. Keep account details, contact information, private website content, and operational configuration out of the recording.
